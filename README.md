## 🌌 Overview

This repository houses the personal engineering portfolio of **Harsh Bhadoriya** (B.Tech CSE, GLA University). The application is an immersive, performance-tuned web experience combining real-time 3D WebGL graphics, multi-agent AI architecture storytelling, interactive sandboxes, and deep technical project case studies.

### Key Highlights
- 🛸 **Cinematic Arrival Sequence**: Interactive 3D aircraft fly-by sequence with shockwave simulation, custom sonic audio synthesized via Web Audio API, and dynamic camera choreography in Three.js.
- 🌐 **Story Constellation Background**: Continuous scroll-aware 3D particle and multi-agent neural network visualization operating at a locked 60–120 FPS.
- ⚡ **Interactive AI Command Terminal**: Live client-side terminal interface with autocomplete, system diagnostics, tech stack inspections, and project execution simulations.
- 🛠️ **Deep Project Case Studies**: Complete breakdown of flagship architectures like *PolyTutor AI*, *CodeCollab AI*, *OmniSearch Multi-Modal Agent*, and *CloudScale DevOps Cockpit*.
- 🎯 **Performance Tuned**: IntersectionObserver-based WebGL pausing, zero-re-render hardware-accelerated cursor lerping, and smooth fluid typography without layout shifts.

## 📦 Quick Start & Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshbhadoriya/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the port indicated in your console) to view the portfolio.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Lint and type-check:**
   ```bash
   npm run lint
   ```
